# 系統助手

Agora 可以作為 Android 系統助手：長按電源鍵（或使用裝置的助手手勢）即可在任何應用程式上方開啟 Agora 浮動視窗，提問並直接獲得回答，無需離開目前的應用程式。

## 設定

1. 開啟 Agora 的 **設定 → 系統助手**。
2. 點選 **開啟系統設定**。
3. 選擇 **Agora** 作為預設數位助手應用程式。

該頁面的狀態列會顯示 Agora 目前是否為預設助手。具體的喚醒手勢（長按電源鍵、角落滑動或長按 Home 鍵）取決於您的裝置和 Android 版本。

## 使用浮動視窗

輸入問題並點選 **傳送**，回答會直接顯示在浮動視窗中。點選 **在 Agora 中開啟** 跳轉到完整對話，或點選 **關閉** 退出浮動視窗。

每個浮動視窗對話都是普通的 Agora 對話，可以完整使用您配置的提供商和模型，並會像其他聊天一樣出現在對話列表中。

## 螢幕上下文

當浮動視窗在其他應用程式上方開啟時，Agora 可以看到螢幕上的內容——類似 Gemini 的「詢問此螢幕」。當螢幕內容可用時，會出現 **包含此螢幕** 選項；點選可切換是否將該上下文隨問題一起傳送。

設定 → 系統助手 中的兩個開關控制擷取內容：

- **附加螢幕截圖**（預設開啟）：將目前螢幕的截圖作為圖片附件傳送，多模態模型可以看到版面配置、圖像和影片。
- **包含螢幕文字**（預設開啟）：將螢幕上可見的文字作為純文字上下文傳送（最多 8,000 個字元）。

保護內容的應用程式（銀行、密碼欄位、DRM 影片）不會提供任何內容——選項不會出現。

## 語音輸入

點選麥克風按鈕並說話——說話時字詞會即時顯示在輸入框中（部分結果會串流填入）。準備好後點選 **傳送**；聽寫絕不會自動提交。首次使用時 Agora 會請求麥克風權限。在支援的裝置上（Android 12+）辨識在本機進行，否則使用系統語音服務。可透過 設定 → 系統助手 中的 **語音輸入** 開關關閉。

## 重用對話

預設情況下，每次啟動都會建立新對話。在 設定 → 系統助手 中啟用 **重用助手對話**，即可保留一個持續的助手聊天。

## 隱私

浮動視窗中的提問會傳送到您配置的提供商，與在主應用程式中輸入的訊息完全相同。在您點選傳送之前，不會傳送任何內容。
