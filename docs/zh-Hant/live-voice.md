# 即時語音通話

大聲對助手說話，聽它語音回答——由 Gemini Live API 驅動的完整語音對話，使用你自己的 Google API 金鑰。

## 啟用

即時語音預設關閉（這是預覽功能，且原生音訊模型在通話期間持續消耗 token——而不只是按訊息計費）。

1. 在 Agora 中開啟 **設定 → 助手 → 即時語音通話**。
2. 閱讀費用說明並啟用 **語音通話**。

助手浮動視窗和聊天頂欄中會出現一個 **通話** 按鈕。

## 撥打通話

1. 開啟助手（長按電源鍵或使用裝置的手勢）。
2. 點擊 **通話** 按鈕。Agora 開啟通話畫面，首次使用時會請求麥克風權限。
3. 自然地說話。模型偵測到你講完後會語音回答。你可以隨時直接開口打斷它（搶話）——它會立即停下來聽。

通話畫面開啟期間，即使切換應用程式麥克風也持續運作（會出現一則常駐通知）。點擊 **掛斷** 結束通話。如果你的裝置沒有硬體回音消除器，Agora 會建議使用耳機。

通話畫面會即時顯示你與助手正在說的字幕 —— 目前這一輪已說出的內容，以及已完成輪次的歷史 —— 並配有一個隨對話起伏的通話光球。**靜音** 只會關閉你的麥克風，不會打斷正在說話的助手。

## 對話記錄

每完成一輪對話，就會作為普通訊息保存到專屬的 **語音通話** 會話中，顯示在會話列表裡——音訊本身從不保存。通話中途掛斷時，你已說出的內容會被保留（回覆為空），而不會遺失。

預設情況下，新的通話會繼續最近一次語音通話的會話。在設定中關閉 **重用語音對話** 可讓每次通話新建會話。

## 重新連線

手機網路會斷，通話不會。Agora 會自動重新連線（出現簡短的 **重新連線中…** 提示），並在 Google 約 2 小時的恢復視窗內繼續對話。

## 模型與語音

通話使用 **設定 → 助手 → 即時語音通話** 中設定的 Gemini Live 模型（預設：`gemini-3.1-flash-live-preview`）。Live 模型是預覽版且更新頻繁——如果通話無法啟動，請參照 [Google Live API 文件](https://ai.google.dev/gemini-api/docs/live) 用目前名稱更新其中的模型 ID。語音（預設：`Kore`）也可以改為任何預建語音名稱。

## 隱私

音訊使用你的 API 金鑰從裝置直接串流傳輸到 Google 的 Gemini Live 端點——與所有 Agora 供應商相同的 BYOK 信任模型。音訊永遠不會被錄製或儲存在裝置上，也不會被 Agora 儲存；本機只保存文字記錄。麥克風僅在通話期間使用。
