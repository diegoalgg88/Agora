# 系统助手

Agora 可以作为 Android 系统助手：长按电源键（或使用设备的助手手势）即可在任何应用上方打开 Agora 悬浮窗，提问并直接获得回答，无需离开当前应用。

## 设置

1. 打开 Agora 的 **设置 → 系统助手**。
2. 点击 **打开系统设置**。
3. 选择 **Agora** 作为默认数字助手应用。

该页面的状态行会显示 Agora 当前是否为默认助手。具体的唤醒手势（长按电源键、角落滑动或长按 Home 键）取决于您的设备和 Android 版本。

## 使用悬浮窗

输入问题并点击 **发送**，回答会直接显示在悬浮窗中。点击 **在 Agora 中打开** 跳转到完整对话，或点击 **关闭** 退出悬浮窗。

每个悬浮窗对话都是普通的 Agora 对话，可以完整使用您配置的提供商和模型，并会像其他聊天一样出现在对话列表中。

## 屏幕上下文

当悬浮窗在其他应用上方打开时，Agora 可以看到屏幕上的内容——类似于 Gemini 的"询问此屏幕"。当屏幕内容可用时，会出现 **包含此屏幕** 选项；点击可切换是否将该上下文随问题一起发送。

设置 → 系统助手 中的两个开关控制捕获内容：

- **附加屏幕截图**（默认开启）：将当前屏幕的截图作为图片附件发送，多模态模型可以看到布局、图像和视频。
- **包含屏幕文本**（默认开启）：将屏幕上可见的文本作为纯文本上下文发送（最多 8,000 个字符）。

保护内容的应用（银行、密码字段、DRM 视频）不会提供任何内容——选项不会出现。

## 语音输入

点击麦克风按钮并说话——说话时字词会实时显示在输入框中（部分结果会流式填充）。准备好后点击 **发送**；听写绝不会自动提交。首次使用时 Agora 会请求麦克风权限。在支持的设备上（Android 12+）识别在本地进行，否则使用系统语音服务。可通过 设置 → 系统助手 中的 **语音输入** 开关关闭。

## 复用对话

默认情况下，每次激活都会创建新对话。在 设置 → 系统助手 中启用 **复用助手对话**，即可保留一个持续的助手聊天。

## 隐私

悬浮窗中的提问会发送到您配置的提供商，与在主应用中输入的消息完全相同。在您点击发送之前，不会发送任何内容。
