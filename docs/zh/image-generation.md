# 图像生成

打开**设置 → 图像生成**选择图像工具使用的后端、模型和默认尺寸。

## 后端

同一个 `generate_image` 工具由两种后端提供服务：

- **标准（兼容 OpenAI）**——默认。使用所选模型提供商的凭据及其 `/images/generations` 端点。
- **AI Horde**——志愿工作者的众包网络。请求进入原生 Horde v2 API 的队列，生成可能需要数分钟，匿名 Key `0000000000`（队列优先级最低）时尤甚。在 `aihorde.net/register` 注册个人 Key 后优先级会随时间提高；系统会自动复用在提供商页配置的 AI Horde Key。

## 模型与凭据

所选值标识一个已配置的 `提供商:模型`。Agora 从该提供商解析 API Key 和 Base URL；本页没有独立的图片密钥或端点。选择器优先展示可能支持图片的模型，也可显示全部已配置模型。

模型即使未启用于普通聊天，也可能从提供商同步并用于图片生成；实际能力由提供商和模型决定。

选择 AI Horde 后端时，模型选择器列出当前在线的图像模型（checkpoint，如 Stable Diffusion、FLUX），而非聊天模型；留空表示让任意可用节点接单。AI Horde 请求始终以 `nsfw=false` 并启用 Horde 替换过滤器运行。

默认尺寸为 `1024x1024`。提示词和请求参数会发送给所选提供商，生成媒体保存到设备上的对话/工具数据中。详见[隐私与安全](privacy.md)。
