# 实时语音通话

大声对助手说话，听它语音回答——由 Gemini Live API 驱动的完整语音对话，使用你自己的 Google API 密钥。

## 启用

实时语音默认关闭（这是预览功能，且原生音频模型在通话期间持续消耗 token——而不只是按消息计费）。

1. 在 Agora 中打开 **设置 → 助手 → 实时语音通话**。
2. 阅读费用说明并启用 **语音通话**。

助手悬浮窗和聊天顶栏中会出现一个 **通话** 按钮。

## 拨打通话

1. 打开助手（长按电源键或使用设备的手势）。
2. 点击 **通话** 按钮。Agora 打开通话界面，首次使用时会请求麦克风权限。
3. 自然地说话。模型检测到你讲完后会语音回答。你可以随时直接开口打断它（抢话）——它会立即停下来听。

通话界面打开期间，即使切换应用麦克风也持续工作（会出现一条常驻通知）。点击 **挂断** 结束通话。如果你的设备没有硬件回声消除器，Agora 会建议使用耳机。

通话界面会实时显示你与助手正在说的话的字幕 —— 当前这一轮已说出的内容，以及已完成轮次的历史 —— 并配有一个随对话起伏的通话光球。**静音** 只会关闭你的麦克风，不会打断正在说话的助手。

## 对话记录

每完成一轮对话，就会作为普通消息保存到专属的 **语音通话** 会话中，显示在会话列表里——音频本身从不保存。通话中途挂断时，你已说出的内容会被保留（回复为空），而不会丢失。

默认情况下，新的通话会继续最近一次语音通话的会话。在设置中关闭 **复用语音对话** 可让每次通话新建会话。

## 重连

手机网络会断，通话不会。Agora 会自动重连（出现简短的 **重新连接中…** 提示），并在 Google 约 2 小时的恢复窗口内继续对话。

## 模型与语音

通话使用 **设置 → 助手 → 实时语音通话** 中配置的 Gemini Live 模型（默认：`gemini-3.1-flash-live-preview`）。Live 模型是预览版且更新频繁——如果通话无法启动，请参照 [Google Live API 文档](https://ai.google.dev/gemini-api/docs/live) 用当前名称更新其中的模型 ID。语音（默认：`Kore`）也可以改为任何预置语音名称。

## 隐私

音频使用你的 API 密钥从设备直接流式传输到 Google 的 Gemini Live 端点——与所有 Agora 供应商相同的 BYOK 信任模型。音频永远不会被录制或存储在设备上，也不会被 Agora 存储；本地只保存文字记录。麦克风仅在通话期间使用。
