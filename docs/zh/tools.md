# 代理工具

Agora 可让模型在多轮生成中调用工具。

## 可用能力

按设置、构建和提供商能力，可用工具包括：网络搜索、图像生成、活跃/已保存记忆、历史对话搜索、MCP、技能（Skills）、任务与循环自动化、Conch/SSH 命令与持久任务、远程文件操作、`view_image`、F-Droid 构建中的 Alpine 沙盒，以及助手设备操作：闹钟、日历事件、打开文件与链接、基于 IP 的定位、本地时间和设备通知。

打开**设置 → 工具**可查看各工具界面：统一的**工具**页面（助手设备操作）、**网络搜索**、**对话搜索**、**Shell**、**MCP** 和**自动化**。

## 助手设备工具

打开**设置 → 工具 → 工具**可逐个启用设备操作。每个工具默认关闭：

- **设置闹钟** —— 在设备时钟应用中暂存一个闹钟或倒计时。
- **打开文件** —— 用 Android 默认应用打开沙盒文件。
- **日历** —— 在设备日历上创建、列出、更新和删除事件（首次启用日历工具时会请求 Android 日历权限）。
- **获取位置** —— 通过 ipwho.is 服务基于设备 IP 估算的城市级大致位置。
- **获取本地时间** —— 当前日期、时间和时区。
- **打开 URL** —— 在浏览器或默认应用中打开链接。
- **发送通知** —— 在设备上发布一条通知。

!!! warning "破坏性操作需要你的批准"
    设置闹钟以及创建、更新、删除日历事件会先**暂存**：模型不会直接执行。对话中会出现一个带操作摘要的横幅，只有你点击**批准**按钮后，设备上才会真正执行更改。**放弃**则会移除暂存的操作。

只读操作（打开 URL、列出事件、定位、时间、通知）会直接执行，但每个工具仍只会收到执行所需的参数。

## 权限与默认值

网络搜索、活跃记忆、已保存记忆、历史对话访问和全局 Shell 权限默认开启；Shell 仍需先配置设备，并遵循该设备的确认策略。自动化工具和所有助手设备工具默认关闭。MCP 按服务器与工具开关控制。

工具调用和结果会进入对话协议，并可能在后续轮次发送给模型。外部工具会收到执行所需参数，启用前应核对服务器和权限。图像生成与嵌入使用各自所选提供商的凭据。
